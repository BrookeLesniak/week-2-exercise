What did you build? I built a booking feature for my week-2-exercise website using just HTML, CSS, and Javascript- no backend.
How did micro-iteration feel? Was working in small steps natural or frustrating? Why? Micro iteration felt more like actually coding to me because the process is similar to what I would do while coding without AI. I think that overall I learned a lot more about the process and technical aspects of the code this way. I also had more of a chance to ask questions and review the code in small chunks so that it felt less overwhelming to look at and review.
What did self-review catch? When you asked the AI to review its own code, what issues did it find? Give at least one specific example. THe self review was very helpful as I feel like it really caught a lot. THe biggest issue it caught was in step 3 as there was a timezone bug that could cause future issues and let people book for dates in the past.
Tool impressions. What did you like or dislike about [Copilot Agent / Claude Web]? For my tool I used Claude and while it worked well I think I prefer using Claude in the terminal just because it has a lot more features and capabilities. I ran into a couple of  issues while trying to complete the assignment in claude web, one problem is that it didn't have complete access to all of my files and code as I updated it so I had to manually copy and paste and I felt like that left more room for error. I also ran into errors  with sessions running out and the api bug that was mentioned in the discord chat so I feel like overall I enjoyed using claude in terminal more.
